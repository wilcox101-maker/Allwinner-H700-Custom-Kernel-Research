# Display layer (task R19): upstream patch series carried on top of torvalds/linux 97d73c8 and
# patches/linux/0001-0006, by reference only. tools/apply_upstream.py downloads each series from
# kernel patchwork, checks every patch's `git patch-id --stable` (a hash of the code change only,
# so review tags patchwork adds later don't break it), applies the listed patches with the fixes
# below, and commits each with its original author, date and message. Nothing from these patches
# is stored in this repository.
#
# Format:
#   series <patchwork id> <version> <date> <author>  <title>
#   patch  <n> <patch-id>  apply|skip  [reason]
#   fix    <n> replace <old>|<new>          literal text edit of the downloaded patch
#   fix    <n> drop-hunk <text>             remove the hunk that contains <text>
#   fix    <n> reanchor                     a pure-addition hunk whose context drifted: insert its
#                                           lines before its first trailing-context line, which
#                                           must occur exactly once in the target file
# Fix text is literal (no escapes). For replace, exactly one space follows the word "replace";
# everything after it, leading spaces included, is <old>|<new>.
